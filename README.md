# Yohe Comment Helper
[![Chrome Extension](https://img.shields.io/badge/Chrome-Extension-blue.svg)](https://chrome.google.com/webstore)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

> 专为 shturl.c 站点设计的评论表单自动化助手，Chrome / Edge 浏览器扩展

## ✨ 功能介绍
Yohe Comment Helper 是面向 shturl.c 游戏详情页的评论辅助扩展，自动填充评论表单、自动计算加法验证码，支持批量自动评论，同时做了防重复提交控制。

✅ **核心特性**
- 📝 评论话术库：自定义话术，强制校验 3–5 个汉字，避免违规
- 🎲 两种昵称&邮箱模式：
  - 模式A：从自定义昵称库、邮箱库随机抽取
  - 模式B：程序随机生成字母数字昵称+随机域名邮箱（无汉字）
- 🔢 自动识别并填写页面加法验证码
- 🚀 自动提交（小飞机按钮）+ 页面刷新（可开关，谨慎使用）
- 🛡️ **URL去重机制（重点）**：开启自动提交后，同一个页面网址只会自动提交一次，持久化记录，防止重复灌水
- 🧩 手动填写不受去重限制：随时可以手动触发填充、提交同页面
- 🧹 一键清除全部已提交网址记录，重置自动提交黑名单
- 📦 所有配置、话术库、提交记录全部保存在浏览器本地，不上传任何服务器

## 📸 使用说明
1. 下载本仓库源码，或者下载 Release 压缩包
2. 打开 Chrome / Edge 扩展管理页面 `chrome://extensions/`
3. 开启【开发者模式】→【加载已解压的扩展程序】，选中源码文件夹
4. 打开 shturl.c 的游戏详情页，点击工具栏扩展图标打开控制面板
5. 参数说明：
   - 评论内容：单条预览，支持从话术库随机抽取
   - 昵称 / 邮箱：可手动填写，或开启程序随机生成
   - `覆盖网页已有昵称邮箱`：开启后会覆盖网页缓存的资料
   - `自动从库随机抽取`：每次填充自动随机挑选评论、昵称、邮箱
   - `程序随机生成昵称&邮箱`：忽略昵称、邮箱文本库，代码随机生成
   - `填写完成后自动点击发布并刷新`：高危开关，开启后自动提交，**同一个URL只会自动跑一次**
   - `清除已提交网址记录`：清空自动提交记录，允许页面再次自动提交

> ⚠️ 重要提醒
> 1. 本扩展**仅用于 shturl.c 站点**，不要用于其他网站
> 2. 自动提交开关请谨慎开启，自动提交会直接发送评论，有风控风险
> 3. 所有数据存储在浏览器本地，清除浏览器数据会丢失话术库和提交记录
> 4. 仅用于个人学习、测试，请勿恶意批量灌水，遵守站点规则
